# Kalkulator Cinta by Yarka Ganteng

**Didedikasikan khusus untuk Yuda**  
Karena tiap baris kodenya ditulis sambil mikirin kamu (uhuk).

---

Pernah mikir, "Seberapa besar sih cinta Yarka ke Yuda?"  
Tenang, sekarang kamu gak perlu nanya dukun—cukup buka kalkulator ini, dan biar HTML, CSS, dan JavaScript yang jawab.

## Fitur-fitur cinta:
- Masukin nama kamu (Yuda, ya siapa lagi).
- Masukin nama aku (Yarka, tentu aja).
- Klik tombol cinta.
- Lihat seberapa cocok kita menurut semesta (atau setidaknya, menurut logika acak JavaScript).

## Cara Pakai:
1. Buka `indeks.html`.
2. Isi nama kamu (aku tahu kamu udah tahu namanya siapa).
3. Klik tombolnya.
4. Siap-siap deg-degan.

## Kenapa dibuat?
Karena nulis kode ini rasanya kayak pas Yarka lagi sama Yuda, cenat cenut.  
Dan semoga Yuda tahu, kalau ini bukan sekadar proyek kecil, tapi bentuk sayang dari Yarka yang sok bisa ngoding (demi abang sayang).
